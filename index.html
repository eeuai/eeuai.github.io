GitHub 연결

게임을 올리고 지우려면 이 사이트의 GitHub 저장소에 쓸 수 있는 토큰이 필요해요. 구경과 플레이는 연결 없이도 돼요.

  1. GitHub 토큰 만들기 페이지를 열어요.
  2. Repository access에서 Only select repositories를 고르고 이 사이트 저장소만 골라요.
  3. Permissions → Contents를 Read and write로 바꾸고 토큰을 만들어요.
  4. 만든 토큰을 아래에 붙여넣어요. 친구도 저장소 협업자(Collaborator)로 초대받은 뒤 자기 토큰을 만들면 돼요.
